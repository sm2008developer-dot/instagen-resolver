INSTAGEN RESOLVER SERVER (ঐচ্ছিক, কিন্তু রিয়েল ডাউনলোডের জন্য দরকার)
=====================================================================

এটা কী: অ্যাপ যে Instagram লিংক পাঠায়, এই ছোট সার্ভার সেটা থেকে সরাসরি ভিডিও/ছবির লিংক বের করে
অ্যাপকে ফেরত দেয়। অ্যাপ তারপর নিজেই ফাইল ডাউনলোড করে (রিয়েল প্রগ্রেস সহ)।

১) নিজের পিসিতে টেস্ট (Python 3.9+):
     pip install -r requirements.txt
     python app.py
     ব্রাউজারে খুল: http://localhost:8080/resolve?url=<পাবলিক রিল লিংক>

২) অনলাইনে হোস্ট (HTTPS লাগবেই, অ্যাপ http নেয় না):
   Render / Railway / Fly.io / নিজের VPS - এই ফোল্ডারটা আপলোড কর।
   Start command: gunicorn app:app --bind 0.0.0.0:$PORT --timeout 90
   হোস্ট হলে তোর লিংক হবে যেমন: https://তোর-অ্যাপ.onrender.com

৩) অ্যাপে বসানো - AppConfig.java:
     static final String RESOLVER_ENDPOINT = "https://তোর-অ্যাপ.onrender.com/resolve";
   তারপর অ্যাপ আবার বিল্ড কর।

সীমাবদ্ধতা (সৎভাবে):
- শুধু পাবলিক পোস্ট/রিল। প্রাইভেট বা লগইন-লাগা কনটেন্ট কাজ করবে না (অ্যাপ সেটা স্পষ্ট বলবে)।
- ছবির পোস্ট ও স্টোরি অনেক সময় ব্যর্থ হয়। Instagram প্রায়ই বদলায়, তাই মাঝে মাঝে
  `pip install -U yt-dlp` দিয়ে আপডেট রাখতে হবে।
- ফ্রি হোস্টে প্রথম রিকোয়েস্ট ধীর হতে পারে (ঘুমিয়ে থাকে)।
- Instagram-এর শর্ত ও তোর দেশের আইন মানার দায়িত্ব তোর। Play Store-এ এমন ডাউনলোডার অ্যাপ সাধারণত
  অনুমোদন পায় না, তাই এটা নিজের ব্যবহার/সাইডলোডের জন্য ভাবিস।
- এখানে কোনো Instagram লগইন বা কুকি ব্যবহার হয় না।
